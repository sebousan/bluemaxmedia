## Fonts

Declared in [assets/sass/base/_fonts.sass](assets/sass/base/_fonts.sass), served from `static/assets/fonts/`: PP Monument Extended 400 and 800, Krona One 400. Bootstrap Icons is generated by `yarn build:icons`.

- **WOFF2 only, subset**: PP Monument Extended is cut down to the Google Fonts `latin` range plus `Ÿ`, Latin Extended-A and the combining accents. That covers athlete and brand names from other European languages (Matěj Švancer…). The subset drops the stylistic sets, alternates, superscripts and case-sensitive forms, which the CSS does not use, and keeps kerning, ligatures and hinting: 30 KB down to about 24 KB per file. Krona One is already the Google Fonts `latin` subset and is unchanged. A character outside the range falls back to the next font in the stack.
- **Originals** are kept in `archives/fonts/`, which Hugo does not publish.
- **Preload**: [layouts/partials/head/preload.html](layouts/partials/head/preload.html) preloads PP Monument Extended Black, used by the headings visible without scrolling on every page, so it loads alongside `main.css` instead of after it. Regular and Krona One are left out on purpose: every preload takes bandwidth from `main.css`, and Krona One (buttons) is not used on every page. The URL must match `_fonts.sass`.
- **Cache**: `/assets/fonts/PPMonumentExtended/*` and `/assets/fonts/KronaOne/*` are served as `immutable` for one year ([static/_headers](static/_headers)). Never replace one of these fonts under the same file name: give the new file a new name, for example `PPMonumentExtended-Black.v2.woff2`, and update `_fonts.sass` and `preload.html`. Bootstrap Icons is left out: `yarn build:icons` rewrites it under the same name.

To regenerate a subset (`pip install fonttools brotli`):

```sh
LATIN="U+0000-00FF,U+0131,U+0152-0153,U+0178,U+02BB-02BC,U+02C6,U+02DA,U+02DC,U+0304,U+0308,U+0329,U+2000-206F,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD"
EXT="U+0100-017F,U+0300-036F"
pyftsubset archives/fonts/PPMonumentExtended/PPMonumentExtended-Black.woff2 --unicodes="$LATIN,$EXT" \
  --flavor=woff2 --output-file=static/assets/fonts/PPMonumentExtended/PPMonumentExtended-Black.v2.woff2
```
